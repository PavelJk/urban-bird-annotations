# Аннотационная схема проекта «Городские птицы»

## 1. Назначение схемы
Документ описывает правила разметки неструктурированных данных
(текст, изображения, аудио) для проекта по наблюдению за городскими птицами.

## 2. Модальности
- текст — описания наблюдений, заметки, статьи;
- изображения — фотографии птиц;
- аудио — записи пения и криков птиц.

## 3. Уровни разметки

| Модальность | Уровень 1 | Уровень 2 | Уровень 3 |
|---|---|---|---|
| Структура текста | Документ | Раздел | Параграф |
| Текст | Именованная сущность | Часть речи | Токен |
| Изображения | Область | Объект (птица) | Деталь |
| Аудио | Фрагмент | Вокализация | Сегмент |

## 4. Типы именованных сущностей (текст)

| Тег | Что обозначает | Примеры |
|---|---|---|
| SPECIES | вид птицы | домовый воробей |
| LOCATION | место | парк, двор |
| DATE_TIME | время | весной, утром |
| BEHAVIOR | поведение | поёт, гнездится |
| COLOR | цвет оперения | коричнево-серое |
| SOUND | тип звука | пение, крик |
| SOUND_TYPE | уточнение типа звука | SONG, CALL, TRILL |
| BODY_PART | часть тела при описании цвета | грудка, голова, хвост |

## 5. Классы объектов на изображениях (ЛР №5)

| Класс | Описание | Латинское название |
|---|---|---|
| SPARROW | домовый воробей | Passer domesticus |
| PIGEON | сизый голубь | Columba livia |
| TIT | большая синица | Parus major |
| MAGPIE | сорока | Pica pica |

## 6. Классы деталей на изображениях (ЛР №5)

| Класс | Что обозначает |
|---|---|
| BEAK | клюв |
| TAIL | хвост |
| WING | крыло |
| PLUMAGE | оперение |
| LEG | лапа |

## 7. Атрибуты изображений (ЛР №5)

| Атрибут | Тип | Значения |
|---|---|---|
| pose | строка | сидит, стоит, летит, ходит |
| occlusion | строка | нет, частично, полностью |
| plumage_color | строка | коричнево-серое, серо-сизое, жёлтое, чёрно-белое |
| age_sex | строка | самец, самка, птенец, неизвестно |
| confidence | число | 0–1 |

## 8. Форматы хранения
- Текст — CoNLL-U.
- Изображения — CVAT JSON/XML.
- Аудио — TextGrid.

## 9. Верификация
- перекрёстная разметка 10–15 % данных;
- критерии: Cohen's kappa ≥ 0,8; IoU ≥ 0,75;
- выборочная проверка каждого 5-го файла.

## 10. История изменений
- ЛР №2 — создана схема (текст, изображения, аудио).
- ЛР №3 — добавлены SOUND_TYPE, BODY_PART.
- ЛР №5 — добавлены классы объектов, классы деталей и атрибуты для изображений.
